## Starting point

`previous/$prev_exp/` holds the code and notes of an earlier experiment, in which an earlier session of an AI agent solved "$prev_title". That code can walk along paths, start, stop, turn and handle obstacles; its hands, fingers and arms have never held anything. Read its `NOTES.md` first. Reuse it, change it or replace parts of it, whatever gives the best result. Do not modify the files in `previous/`; build your own version in this directory.
