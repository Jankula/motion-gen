## Starting point

`previous/$prev_exp/` holds the code and notes of an earlier experiment, in which an earlier session of an AI agent solved "$prev_title". That code can walk, stop and turn, bend down, hold and carry a box with both hands, compute arm and finger poses, and keep the body's centre of mass over the feet. It has never thrown or caught anything, and the person has never stood on one foot. Read its `NOTES.md` first. Reuse it, change it or replace parts of it, whatever gives the best result. Do not modify the files in `previous/`; build your own version in this directory.
