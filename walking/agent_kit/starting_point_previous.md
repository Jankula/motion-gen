## Starting point

`previous/$prev_exp/` holds the code and notes of the previous experiment, in which an earlier session of an AI agent solved an earlier task: "$prev_title". Read its `NOTES.md` first. Reuse it, change it or replace parts of it, whatever gives the best result. Do not modify the files in `previous/`; build your own version in this directory.

The earlier tasks are in `tasks/`: $earlier_list. Your `make_motion.py` must still produce good motion for them, so check each with `evaluate.py` too.
